# Declaration of AI tools and external code

## AI tools

OpenAI ChatGPT (GPT-6) was used as an AI assistant to help interpret the uploaded assignment brief and supplied research papers, structure the project, draft/organize code, and prepare report text. The core recommendation and evaluation code was executed and unit-tested in this environment. The Streamlit interface is included but must be launched after installing the packages in requirements.txt. The submitting students must review the project, understand each module, run it independently, make any required changes, and follow the institution's academic-integrity and AI-disclosure rules.

## External code

No third-party project repository or codebase was copied into this submission. The project source files were written for this mini-project. The implementation imports standard open-source Python libraries listed in `requirements.txt` (NumPy, pandas, scikit-learn, Matplotlib, Streamlit, and python-docx). The optional MovieLens downloader uses Python's standard-library URL and ZIP utilities.

## Data provenance

The included rating interactions are synthetic and created by `scripts/generate_demo_data.py`; they are not obtained from real users or MovieLens. Movie titles are used as catalog metadata and the short overview text is written for this project. `scripts/download_movielens.py` is an optional downloader/converter for the GroupLens MovieLens 100K dataset; use of that dataset must be acknowledged when used.
